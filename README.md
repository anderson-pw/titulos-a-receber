# Títulos a Receber

Painel HTML com visão executiva, detalhamento por título e conferência das bases SE1 e SE5 do Protheus, com a paleta de cores do Grupo Decio.

## Acesso

O painel é publicado pelo GitHub Pages a partir da branch `main`, na raiz deste repositório.

## Como usar

1. Abra o painel publicado.
2. Clique em **Atualizar bases**.
3. Selecione os CSVs da SE1 e da SE5, separados por ponto e vírgula.
4. Use os filtros de mês, filial, situação, cliente ou título.
5. Exporte o detalhamento ou a conferência em CSV para consultas e tratativas.

As bases são processadas no navegador e valem nesta sessão. A versão pública abre aguardando os arquivos. O painel contém os critérios de cálculo, a origem dos registros e as ressalvas da conciliação.

## Estrutura

- `index.html`: aplicação completa, sem dependências externas.
- `.nojekyll`: publicação estática no GitHub Pages.
